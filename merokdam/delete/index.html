계정과 관련 데이터 삭제

미록담 계정 탈퇴와 계정에 연결된 일기·자서전·첨부 미디어 등 관련 데이터의 삭제를 요청합니다.

계정 삭제 요청 메일 작성

계정은 유지하고 데이터 삭제

삭제를 원하는 일기·자서전·첨부 미디어의 종류와 날짜를 적어 주세요. 계정 탈퇴를 함께 요청하지 않은 경우 계정은 유지하는 요청으로 접수합니다.

데이터 삭제 요청 메일 작성

요청 후 처리 과정

  1. 가입 이메일 또는 로그인 방식과 삭제 범위를 적어 메일을 전송합니다.
  2. 담당자가 계정 소유 여부와 요청 범위를 확인합니다. 비밀번호나 로그인 인증번호는 요청하지 않습니다.
  3. 삭제할 항목과 별도 보관이 필요한 항목·기간이 있다면 안내한 뒤 처리합니다.
  4. 실제 처리 결과를 회신합니다. 삭제된 데이터는 복구할 수 없으므로 범위를 확인해 주세요.
