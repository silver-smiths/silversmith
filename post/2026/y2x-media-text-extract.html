유튜브 자막·웹페이지 본문 텍스트 추출 — AI에 바로 넣는 자료 수집법, y-to-x

유튜브 영상 자막과 웹페이지 본문을 URL 하나로 깨끗한 텍스트로 추출하는 무료 도구. 자동 생성 자막·타임스탬프·마크다운 구조 추출 지원. ChatGPT·Claude·Gemini에 바로 넣는 AI 자료 수집 워크플로와 프롬프트까지. Silversmith가 만든 컨버팅 포털 y-to-x.

Silversmith · 2026년 8월 13일 · 읽는 시간 10분

y-to-x 미디어 변환·텍스트 추출(줄여서 y2x)은 유튜브 영상과 웹페이지를 AI에 바로 넣을 수 있는 깨끗한 텍스트로 바꿔주는 무료 도구입니다. y-to-x는 Silversmith가 직접 만들어 운영하는 무료 온라인 컨버팅 포털로, 이 두 도구는 그중 하나입니다.

자료는 넘치는데, 왜 정리는 늘 어려울까

공부하려고, 일하려고 모아둔 자료 목록을 열어봅니다. 유튜브 강의 영상 세 개, 업계 아티클 다섯 개, 참고하려고 저장한 경쟁사 블로그 두 개. 자료는 충분합니다. 문제는 이걸 쓸 수 있는 형태로 만드는 일입니다.

영상은 1시간을 다시 봐야 내용을 꺼낼 수 있습니다. 2배속으로 돌려도 30분이고, 받아 적다 보면 놓치는 내용이 생깁니다. 웹 아티클은 복사하면 되지 않냐고요? 드래그해서 붙여넣는 순간 알게 됩니다 — 광고 문구, "관련 기사 보기", 사이드바 메뉴, 구독 유도 배너가 본문 사이사이에 껴서 딸려 온다는 걸요.

그리고 2020년대 중반의 우리에게는 이 문제가 더 커졌습니다. 자료를 AI에 넣는 시대가 됐기 때문입니다.

AI 시대, 자료 수집의 병목은 '텍스트화'

ChatGPT, Claude, Gemini 같은 AI로 요약하고, 비교하고, 초안을 만드는 건 이제 특별한 기술이 아닙니다. 그런데 막상 해보면 AI 활용의 진짜 병목은 프롬프트가 아니라 자료를 텍스트로 만드는 단계라는 걸 깨닫게 됩니다.

  • 유튜브 영상은 URL을 AI에 넣어도 내용을 읽지 못하는 경우가 대부분입니다
  • 웹페이지를 통째로 복사하면 광고와 메뉴가 섞여 AI가 본문을 헷갈립니다
  • 지저분한 입력은 지저분한 출력으로 돌아옵니다 — 요약 품질은 입력 품질을 넘지 못합니다

y-to-x의 미디어 변환과 텍스트 추출은 이 병목을 없애는 한 쌍의 도구입니다. 영상이든 웹페이지든, URL 하나를 넣으면 AI에 바로 넣을 수 있는 깨끗한 텍스트가 나옵니다.

도구입력출력
🎬 미디어 변환유튜브 URL(일반·youtu.be·Shorts·영상 ID)자막 전문(언어 선택·자동생성·타임스탬프 옵션) + 영상 정보(제목·채널·설명·조회수)
📄 텍스트 추출웹페이지 URL광고·메뉴 제거한 본문 텍스트 + 글자수, 또는 헤딩 구조(마크다운 목차)

🎬 도구 1: 미디어 변환 — 유튜브 영상을 텍스트로

y-to-x.com/ko/media에 유튜브 URL을 붙여넣으면 두 가지가 나옵니다.

영상 정보 한 번에

제목, 채널명, 설명 전문, 조회수, 재생 시간이 즉시 추출됩니다. 영상 설명에 있는 링크·타임라인·참고자료 목록을 복사하거나, 채널명·제목·URL이 정리된 텍스트 파일로 다운로드할 수 있습니다. 영상 여러 개를 아카이빙할 때 하나하나 열어볼 필요가 없습니다.

자막 전문 추출 — 이 도구의 핵심

  • 모든 등록 언어 지원 — 영어·한국어·일본어·중국어 등 영상에 올라온 자막 언어를 선택해서 추출
  • 자동 생성 자막 지원 — 제작자가 자막을 안 올렸어도 유튜브의 자동 생성(Auto-generated) 자막으로 추출 가능. 사실상 말이 있는 영상 대부분이 대상이 됩니다
  • 타임스탬프 포함/제외 선택 — [3:24] 이 부분에서 중요한 것은... 형태로 받거나, 순수 텍스트만 받거나
  • 복사 버튼 한 번, 또는 .txt 파일 다운로드

지원 URL 형식도 까다롭지 않습니다. 일반 URL(youtube.com/watch?v=...), 단축 URL(youtu.be/...), Shorts, 11자리 영상 ID 직접 입력까지 전부 받습니다. 유튜브 앱에서 '공유 → 링크 복사'한 그대로 붙여넣으면 됩니다.

어디에 쓰냐면

  • 1시간 강의 영상 → 자막 추출 → AI 요약 → 강의 노트
  • 해외 컨퍼런스 발표 → 영어 자막 추출 → AI 번역·요약 → 한국어 브리핑
  • 내 채널 영상들 → 자막 백업 → 블로그 글로 재가공 (크리에이터의 원소스 멀티유즈)
  • 인터뷰 영상 → 타임스탬프 포함 추출 → 인용 위치까지 정확한 기사·리포트

📄 도구 2: 텍스트 추출 — 웹페이지를 텍스트로

y-to-x.com/ko/text에 아티클 URL을 붙여넣으면:

본문만 깔끔하게

광고, 내비게이션 메뉴, 사이드바, 추천 글, 구독 배너를 걷어내고 제목과 본문 텍스트만 추출합니다. 글자수·단어수도 함께 표시되어 분량 확인까지 한 번에 됩니다. 전체 복사 버튼으로 클립보드에 담아 바로 다음 작업으로 넘어가면 됩니다.

웹사이트 구조(목차) 추출

본문이 아니라 사이트가 어떻게 구성됐는지가 필요할 때가 있습니다. 잘 만든 가이드 문서나 경쟁사 페이지의 헤딩(제목) 구조 말이죠. '구조' 탭에 URL을 넣으면 페이지의 헤딩 아웃라인이 마크다운 목차로 추출됩니다.

마크다운 뷰어·에디터 내장

추출한 구조를 그 자리에서 편집하고, 실시간 미리보기로 확인하고, 마크다운(.md)이나 HTML로 복사·다운로드할 수 있습니다. 별도의 마크다운 에디터를 열 필요가 없습니다.

🤖 실전: 두 도구를 조합한 AI 워크플로 4가지

이론은 그만하고, 실제로 어떻게 쓰는지 프롬프트까지 통째로 공개합니다.

시나리오 1 — 영상 강의를 스터디 노트로

① 미디어 변환에서 강의 영상 자막 추출(타임스탬프 제외, 텍스트만) → ② AI에 붙여넣고:

"다음은 강의 자막 전문이야. ① 핵심 개념 5개를 각각 3줄로 정리하고 ② 시험에 나올 만한 예상 질문 10개를 만들어줘. 자막이라 문장이 끊겨 있으니 문맥으로 보정해서 읽어."

영상 10개짜리 커리큘럼도 한나절이면 노트 세트가 됩니다.

팁: 자동 생성 자막은 구두점이 없어서 AI에게 "문장 끊김을 보정해서 읽어라"고 한 줄 넣어주면 품질이 눈에 띄게 좋아집니다.

시나리오 2 — 아티클 5개를 리서치 요약본으로

① 텍스트 추출로 참고 아티클 5개를 각각 추출 → ② AI에 순서대로 붙여넣고:

"아티클 5개를 줄게. 전부 읽고 ① 공통되는 주장 ② 서로 충돌하는 주장 ③ 한 곳에서만 다루는 독자적 내용을 표로 정리해줘. 각 항목에 출처 번호를 달아줘."

드래그 복사였다면 광고 문구가 섞여 "이 아티클은 구독을 권유하고 있다" 같은 오독이 나옵니다. 깨끗한 본문만 넣는 것이 요약 품질의 절반입니다.

시나리오 3 — 잘 만든 페이지의 구조를 벤치마킹

① 텍스트 추출의 '구조' 탭에서 참고 사이트의 헤딩 아웃라인 추출 → ② AI에:

"이건 잘 만들어진 가이드 문서의 목차 구조야. 이 구조의 장점을 분석하고, 같은 구조로 '[우리 주제]' 가이드의 목차를 짜줘."

콘텐츠의 뼈대 설계가 10분 안에 끝납니다. (구조를 참고하는 것과 내용을 베끼는 것은 다릅니다 — 후자는 하지 마세요.)

시나리오 4 — 해외 영상 자료를 한국어 브리핑으로

① 영어 강연·발표 영상의 자막 추출 → ② AI에:

"영어 발표 자막이야. ① 한국어로 500자 요약 ② 발표자의 핵심 주장 3개 ③ 우리 업계(디지털 마케팅)에 적용할 시사점 2개를 정리해줘."

리스닝 실력과 무관하게 해외 자료를 소화할 수 있게 됩니다.

AI 없이도 쓸 곳은 많습니다

  • 인용 정리 — 논문·리포트에 영상 발언을 인용할 때 타임스탬프 포함 자막으로 정확한 출처 표기
  • 자막 아카이빙 — 내 채널 영상의 자막을 .txt로 백업
  • 스크랩 — 사라질지 모르는 아티클의 본문을 텍스트로 보관
  • 번역 의뢰 준비 — 영상 자막을 추출해서 번역가에게 텍스트로 전달

자주 묻는 질문 (FAQ)

Q. 회원가입이 필요한가요?

아니요. 두 도구 모두 회원가입·로그인 없이 사용합니다.

Q. 정말 무료인가요?

네. 다만 서비스 운영(유료 API 비용)을 위해 일부 기능은 짧은 광고 시청 후 이용할 수 있습니다. 결제나 구독은 없습니다.

Q. 자동 생성 자막도 추출되나요?

네. 제작자가 등록한 자막은 물론 유튜브가 자동 생성한 자막도 지원합니다. 자동 생성 자막은 음성 인식 특성상 오탈자가 있을 수 있습니다.

Q. 자막이 아예 없는 영상도 되나요?

자막 트랙이 하나도 없는 영상(음악 영상 등)은 추출할 자막이 없어 영상 정보만 제공됩니다.

Q. 어떤 유튜브 URL 형식을 지원하나요?

일반 영상 URL, 단축 URL(youtu.be), Shorts URL, 11자리 영상 ID 직접 입력을 모두 지원합니다.

Q. 웹페이지 추출이 안 되는 사이트도 있나요?

로그인이 필요한 페이지, 유료 구독 콘텐츠 등 접근이 제한된 페이지는 추출할 수 없습니다.

Q. 추출한 텍스트를 상업적으로 써도 되나요?

도구는 자유롭게 사용하실 수 있지만, 추출된 콘텐츠(자막, 본문)의 저작권은 원저작자에게 있습니다. 요약·참고를 넘어 게시·배포하는 경우 원저작자의 이용 조건을 확인하세요.
