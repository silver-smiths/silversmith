서버 업로드 없는 무료 이미지 변환기 — 포맷·용량·크기·배경 제거, y-to-x

사진을 서버에 올리지 않고 브라우저 안에서 처리하는 무료 이미지 변환기. 포맷 변환(JPG·PNG·WebP·AVIF)·용량/크기 조절·AI 배경 제거·GIF 제작·PDF 이미지 추출을 한 페이지에서. Silversmith가 만든 컨버팅 포털 y-to-x.

Silversmith · 2026년 7월 30일 · 읽는 시간 8분

y-to-x 이미지 변환기(줄여서 y2x)는 사진을 서버에 올리지 않고 브라우저 안에서 포맷·용량·크기 변환과 배경 제거까지 처리하는 무료 도구입니다. y-to-x는 Silversmith가 직접 만들어 운영하는 무료 온라인 컨버팅 포털로, 이미지 변환은 그중 하나입니다.

이미지 변환 사이트, '찜찜'하거나 '불편'하지 않았나요?

이미지 변환 사이트를 쓰다 보면 두 가지 감정이 남습니다.

하나는 찜찜함. 가족사진, 신분증 사본, 업무 문서 캡처를 남의 서버에 업로드하면서 드는 생각 — "이 사진, 저 서버에 남는 거 아냐?" 삭제된다고는 하지만 확인할 방법이 없죠.

다른 하나는 번거로움. 포맷은 A사이트에서 바꾸고, 용량은 B사이트에서 줄이고, 크기는 C사이트에서 조절하고. 같은 이미지를 세 번 업로드하고 세 번 다운로드하는 여정. 그리고 매번 "다운로드 버튼이 어디지?" 하며 광고 사이를 헤매는 시간까지.

y-to-x 이미지 변환기는 이 두 가지를 동시에 해결하려고 만들었습니다. 이미지는 브라우저 밖으로 나가지 않고, 작업은 클릭 한 번에 끝납니다.

🔒 보안: 서버 업로드 없음 — 말이 아니라 구조입니다

y-to-x의 이미지 도구는 변환·배경 제거·GIF 제작 전 과정이 사용자의 브라우저 안에서 처리됩니다.

  • 이미지가 네트워크로 전송되지 않으므로 유출될 서버 자체가 없습니다
  • "업로드 → 서버 처리 → 다운로드" 대기가 없어 변환이 즉시 시작됩니다
  • 신분증, 계약서, 사내 문서 캡처도 안심하고 변환할 수 있습니다

⚡ 편의: 세 가지 작업을 한 번에, 다운로드는 자동으로

포맷 + 품질 + 크기 동시 설정

한 화면에서 출력 포맷(JPG·PNG·WebP·AVIF), 품질 슬라이더, 픽셀 크기를 모두 설정하고 변환 버튼 한 번이면 끝. 사이트 세 곳을 순회할 필요가 없습니다. 변환 후엔 원본 대비 용량이 몇 % 줄었는지도 바로 보여줍니다.

변환이 끝나면, 이미 다운로드되어 있습니다

"변환 완료 → 결과 확인 → 다운로드 버튼 찾기" — 이 마지막 단계도 없앴습니다. 변환이 끝나는 순간 파일이 자동으로 다운로드됩니다. 여러 장이면 ZIP 하나로 자동으로 묶입니다. 수십 장을 변환해도 클릭은 한 번입니다.

다운로드 대신 클립보드 복사도 선택할 수 있습니다. 변환한 이미지를 문서나 채팅창에 바로 붙여넣을 때 편합니다.

① 포맷 변환 — JPG·PNG·WebP·AVIF

포맷·품질·크기 동시 설정, 여러 장 일괄 변환, 즉시 다운로드. WebP·AVIF로 변환하면 같은 화질에 용량이 크게 줄어 블로그·웹사이트 로딩 개선에 효과적입니다.

어떤 포맷을 골라야 할지 모르겠다면 아래 기준을 참고하세요. 용량은 대체로 AVIF < WebP < JPG < PNG 순으로 작은 경우가 많습니다(이미지에 따라 다름).

포맷특징이럴 때 추천
JPG사진에 적합, 투명 미지원, 어디서나 열림(범용 호환)일반 사진, 최대 호환이 필요할 때
PNG무손실·투명 지원, 텍스트/로고 선명, 용량 큼로고·아이콘, 투명 배경, 캡처 화면
WebP손실·무손실·투명 모두 지원, JPG·PNG보다 작음, 최신 브라우저 폭넓게 지원웹사이트·블로그 기본 권장
AVIF최신 고효율, 같은 화질에 가장 작은 편, 지원 환경 확대 중용량 최우선, 최신 환경 대상

② GIF 만들기 — 이미지로도, 동영상으로도

여러 장의 사진을 이어붙여 GIF 애니메이션으로. MP4 동영상 → GIF 변환도 지원합니다. 프레임 순서는 드래그로 조정하고, 완성되는 순간 자동 다운로드됩니다.

③ AI 배경 제거

상품 사진, 프로필 사진의 배경을 AI가 자동으로 제거합니다. 결과물은 PNG(투명배경)·WebP·JPG 중 원하는 포맷으로 즉시 받습니다.

이 작업까지도 브라우저 안에서 처리됩니다 — 인물 사진을 어디에도 업로드하지 않습니다. 그래서 첫 이용 시에만 AI 처리 프로그램(약 100MB)을 다운로드합니다. 서버에 사진을 보내는 대신 AI를 내 브라우저로 가져오는 방식이라고 생각하시면 됩니다. 한 번 받아두면 이후에는 브라우저 캐시를 재사용해 바로 실행됩니다.

④ PDF 이미지 추출

PDF 안의 이미지가 필요할 때, 화면을 캡처하면 화질이 깨지고 확대하면 계단 현상이 생깁니다. y-to-x는 캡처가 아니라 PDF 파일 안에 저장된 이미지 원본을 그대로 꺼내는 방식입니다.

온라인에서 다운로드한 보고서·백서·제안서 속 도표나 사진을 원본 화질 그대로, 깨짐 없이 추출해 발표자료나 문서에 재사용할 수 있습니다. 페이지별로 이미지 개수를 확인하고, 원하는 페이지만 선택해서 추출할 수도 있습니다. (저작권이 있는 자료는 이용 범위를 확인 후 사용하세요.)

이런 분들께 특히 유용합니다

  • 직장인 — 민감한 업무 문서·캡처를 외부 서버에 올리지 않고 변환 (보안)
  • 블로거·웹사이트 운영자 — 수십 장을 WebP/AVIF로 일괄 변환, ZIP으로 한 번에 (편의)
  • 온라인 셀러 — 상품 사진 배경 제거부터 마켓별 포맷 변환까지 한 곳에서
  • 커뮤니티·SNS 이용자 — 동영상 클립을 움짤로, 프로필 사진 배경 제거를 무료로

사용 방법

  1. y-to-x.com/ko/image 접속 — 회원가입, 설치 없음
  2. 상단 탭에서 기능 선택 (포맷 변환 / GIF 만들기 / 배경 제거 / PDF 이미지 추출)
  3. 이미지를 드래그 앤 드롭
  4. 포맷·품질·크기 설정 → 변환 버튼
  5. 끝. 파일은 이미 다운로드되어 있습니다.

자주 묻는 질문 (FAQ)

Q. 정말 이미지가 서버로 전송되지 않나요?

네. 변환·배경 제거·GIF 제작 모두 브라우저 안에서 처리되며, 이미지 자체는 어디로도 전송되지 않습니다.

Q. 배경 제거를 누르니 다운로드가 시작되는데 뭔가요?

사진을 서버로 보내지 않고 브라우저 안에서 AI를 실행하기 위한 처리 프로그램(약 100MB)입니다. 첫 이용 시 한 번만 받으며, 이후에는 브라우저 캐시를 재사용합니다. 사진 자체는 어디로도 전송되지 않습니다.

Q. 무료인가요?

무료이며 회원가입이 필요 없습니다. Silversmith가 만들어 운영하며 광고 수익으로 유지됩니다.

Q. 여러 장을 한 번에 변환할 수 있나요?

네. 여러 장을 올리면 같은 설정으로 일괄 변환되고, ZIP 파일 하나로 자동 다운로드됩니다.

Q. 파일 크기 제한이 있나요?

브라우저에서 처리하는 방식 특성상 기기 성능에 따라 달라질 수 있으나, 일반적인 사진·문서 이미지는 문제없이 처리됩니다.

Q. AVIF로 변환했는데 일부 프로그램·기기에서 안 열려요.

AVIF는 비교적 최신 포맷이라 오래된 뷰어·브라우저에서는 열리지 않을 수 있습니다. 어디서나 열려야 한다면 WebP 또는 JPG로 변환하는 것을 권장합니다.

Q. 인터넷 연결 없이도 쓸 수 있나요?

이미지 처리 자체는 브라우저 안에서 이뤄지지만, 페이지와 AI 배경 제거용 프로그램을 처음 불러올 때는 인터넷 연결이 필요합니다. 한 번 불러온 뒤에는 브라우저 캐시를 재사용합니다.

Q. 변환한 이미지를 상업적으로 사용해도 되나요?

y-to-x는 사용자가 올린 이미지를 변환만 해주는 도구이므로, 변환 결과물의 사용 권리는 원본 이미지의 권리자에게 있습니다. 본인이 촬영·제작했거나 사용 권리를 가진 이미지라면 자유롭게 사용할 수 있고, 타인의 저작물이라면 별도 이용 범위를 확인하세요.
